# 比赛解读

## 你们该抓的评分点

官方手表/手环应用方向强调三类价值：

- 高频任务便捷化：腕上快速输入、提醒、执行，不用反复拿手机。
- 运动健康差异化：利用心率、血氧、压力等健康状态影响计划。
- 创新交互探索：语音、快捷按钮、触摸、短路径操作。

比赛评分结构里，技术难度、产品创新、项目完整度合计占主要分数。因此项目不能只停留在“AI 写一段计划”，需要做到完整闭环。

## 对 VelaPlan 的定位

VelaPlan 不做大而全的生活助手，而做“腕上状态感知计划助手”。用户输入一个统一目标，应用用周期、重要程度、健康状态和天气组织可执行安排；目标内容可以自然混合学习、工作、运动等事项。

## 为什么这样更稳

- 符合手表应用创新赛道，开发门槛比底层移植低。
- 可以用官方模拟器和健康 Mock 数据完成初赛验证。
- 能展示 AI、图形界面、健康数据、腕上执行提醒四类能力。
- 和你们的 SF32LB52-DevKit-LCD 屏幕硬件能自然结合。

## 不建议现在做

- 真正的手环佩戴硬件结构。
- 板载麦克风语音采集。
- 本地大模型推理。
- 全新芯片或系统底层移植。
- 复杂地图旅行规划、日历账号同步、医疗级健康建议。
