# 硬件使用方案

## 当前硬件判断

你们的图片显示的是 SF32LB52-DevKit-LCD 一类开发板，连接 1.85 英寸 390x450 AMOLED 触摸屏。它适合做桌面型手表应用原型展示，但不是真正完整手环。

## 本项目中的硬件角色

- 屏幕：展示计划卡片、健康状态、执行进度。
- 触摸：完成周期/天气设置、任务打卡、调整和反馈选择。
- 按键：可作为返回、开始、确认等快捷操作。
- 串口：查看日志、辅助调试。
- 健康数据：初赛使用模拟器 Mock；真机阶段再接入真实健康接口。

## 不依赖的硬件

- 不依赖板载麦克风。
- 不依赖真实心率传感器。
- 不依赖电池和充电管理。
- 不做底层移植作为主线。

## 推荐表述

初赛阶段，项目基于 openvela 手表模拟器完成核心功能验证，使用 `service.health` Mock 心率、血氧、压力数据。SF32LB52-DevKit-LCD 用于展示屏幕、触摸和腕上交互原型。后续进入真机阶段后，再接入真实传感器数据和设备交互。
