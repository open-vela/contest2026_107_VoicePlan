# 官方交流群提问清单

进群后建议优先确认这些问题：

1. SF32LB52-DevKit-LCD 是否支持直接运行 watch 快应用 `release.rpk`。
2. 如果只在 `vela-miwear-watch-5.0(开发者大赛)` 模拟器完整演示，开发板只做硬件端展示，是否符合初赛要求。
3. `service.health` 当前在手表模拟器里是否只支持心率、血氧、压力三类数据。
4. 语音输入是否允许用手机或电脑端 ASR 转文字后传给快应用演示。
5. MiMo Token Plan 发放后，是否有大赛专用 API Base URL 或模型名。
6. 作品提交时是否必须提交 `release.rpk`，还是源码工程和演示视频即可。
7. AI Coding 日志和 Skills 沉淀的推荐格式是什么。
